Project Title: Vehicle Image Classification
1. What problem will you be investigating? Why is it interesting to you?
My topic of choice is image classification, specifically vehicle image classification. My goal and question is to train my model to be able to accurately identify and sort different types of vehicles. Accurate classification is beneficial to implement for the creation of AI tools.
2. What dataset will you use, and how will you get it?
Through Kaggle I found this dataset: https://www.kaggle.com/datasets/mohamedmaher5/vehicle-classification?select=Vehicles These are the images I will be using for my image classification. The dataset includes over 800 images of each category; cars, motorcycles, bikes, ships, trains, planes, and auto rickshaws. 
3. Have people worked on this problem or similar ones before, if so what are you trying
to do that's different?
As for if anyone else has asked the same problem I would assume parts of the government have used some sort of vehicle image classification to identify traffic violations. Self-driving car companies would also use this strategy for identifying differences between vehicles such as cars, trains, bikes, motorcycles so that their cars respond accordingly.  Assuming that this project has been done before, or something similar, to make my project and question stand out I want to see how many pixels I need to identify the vehicles. 
4. How will you evaluate whether your model works or not? 
I think for evaluating whether my model works I can just use human evaluation simply because I will be able to tell whether my model was able to correctly identify. I will also have an accuracy evaluation and possibly a confusion matrix.
